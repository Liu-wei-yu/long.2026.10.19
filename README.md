# 云海小镇 · Cloud Town

一个跑在浏览器里的 three.js 三渲二（toon / cel-shading）浮空岛小镇：白天 / 黄昏 / 夜晚三时段可平滑切换，房屋带生长动画，可交互。

打开方式：双击 `start.bat`（或在本目录执行 `node server.mjs 5178`），浏览器访问 <http://localhost:5178/>
> 必须走 http，直接双击 index.html 会因为 ES Module 跨域打不开。

---

## 一、操作

| 操作 | 说明 |
|---|---|
| 左键拖拽 / 滚轮 | 旋转、缩放（角度与距离有限制，不会钻到地下） |
| 鼠标悬停房屋 | 描边变金色 + 右侧弹出住户信息卡 |
| 点击房屋 | 镜头推近 + 该栋重新生长一次 |
| 点击路灯 | 单盏开关 |
| 1 / 2 / 3 / 4 | 全景 / 街道 / 广场 / 英雄镜头（相机贝塞尔缓动） |
| D / G / N | 白天 / 黄昏 / 夜晚（2.6s 平滑过渡） |
| 空格 | 重播全城生长 |
| R | 复位视角 |
| H | 隐藏全部 UI |
| 面板滑块 | 0–24 小时连续调时间，拖动即时预览 |

## 二、场景内容

- **浮空岛**：半径 80，顶面草地（顶点色斑块）+ 边缘土壤带 + 12 层岩壁（每圈带随机起伏）+ 岛缘瀑布与雾团
- **云海**：三层 InstancedMesh 云（近层蓬松云团 / 中层云带 / 远处低平云海），各自反向缓慢旋转
- **天空**：自定义 shader 球，三色渐变 + 太阳光晕 + 月亮 + 程序化星空
- **小镇布局**：中央广场（扇形铺装 + 喷泉 + 钟楼）+ 环岛路 + 4 条放射状道路（尽端小圆环广场）
- **房屋 35 栋**：坡屋顶 / 四坡顶 / 平顶三种屋顶，1–3 层，随机墙色、屋顶色、百叶窗、阳台、烟囱、商铺雨棚与发光招牌；每户配绿篱、门前石径、信箱
- **房屋 32 栋 · 按职业建模**：每户有明确主人（面包师 / 花匠 / 邮差 / 钟表匠 / 灯塔看守 / 旧书店老板 / 修伞匠 / 织布工 / 拾云人 / 风车管理员），房屋外形随职业变化——
  - 面包师：条纹雨棚 + 门口双层面包架（真摆面包）+ 麦穗招牌 + 烟囱铁皮帽
  - 花匠：侧面玻璃温室（斜玻璃顶 + 里面四盆花）+ 三层花架 + 墙面藤蔓 + 吊篮
  - 邮差：红色邮筒 + 门口包裹堆 + 公告板 + 载货自行车
  - 钟表匠：窄高三层 + 山墙大钟（刻度/指针）+ 墙上齿轮 + 挑出挂钟招牌
  - 灯塔看守：侧接红白条纹灯塔 + 灯室（夜间发光）+ 观景平台
  - 旧书店：A 字广告牌 + 门口书堆 + 橱窗内书架
  - 修伞匠：墙上挂 4 把伞 + 门口工作台与伞骨
  - 织布工：晾布架（两层绳 + 6 匹布）+ 纱线轴 + 窗内织机
  - 拾云人：屋顶玻璃收云罐（里面云絮）+ 门口玻璃瓶 + 靠墙梯子 + 采云长杆
  - 风车管理员：屋顶小风车 + 门口木桶 + 长杆
  - 通用细节：勒脚、台阶、楼层腰线、窗台、百叶窗、窗下花箱、门檐、门牌、门口灯、檐沟落水管、烟囱、老虎窗、转角石、半木构架
- **业主身份可查**：鼠标悬停房屋会显示真实住户（名字 / 职业 / 一句台词），与外形对应
- **街道道具**：斑马线（含停止线）、中心虚线、路缘石、路灯（灯芯 + 地面光斑）、垃圾桶、长椅、消防栓、花箱、行道树、路牌、矮栅栏、石块
- **广场市集**：4 个红白条纹摊位（带货品与价牌）、同心铺装环、8 组花圃、街心八角凉亭
- **生活细节**：每户绿篱、石径、信箱、自行车、花箱、灌木
- **行人 25 个 + 1 条狗**：低多边形小人（成人/儿童、大衣、围巾、帽子、背包随机），沿三条环线 + 四条放射街的闭合路径行走，带走路循环
  - **红绿灯**：4 条路 × 3 个路口装行人信号灯（0/1 两组相位交替，8.5s 绿 / 6.5s 红），行人到斑马线前会停下等待，灯绿才过街
  - **夜间回家**：约 65% 的人入夜后加速走向自己的“家”（路径上预设的点），到点后缩身消失；天亮再出门
  - **摊位停留**：广场路径上的人有概率在摊位前停下 4~10 秒，转身看向摊位并轻轻晃动
  - **狗跟随**：一条小狗跟着主人，走在身后 1.5 米，四条腿交替跑动；主人停下它就坐下
- **地标**：钟楼（四面表盘 + 指针，夜间表盘发光）、喷泉、风车（叶片旋转）、水塔
- **环境动效**：2 个热气球绕岛缓慢漂移（夜间燃烧器变亮）、夜间 140 点萤火浮动、云海漂移、瀑布流动、烟囱炊烟、风车转动

## 三、三渲二做法

| 环节 | 做法 |
|---|---|
| 明暗分层 | `MeshToonMaterial` + 4 阶 `DataTexture` gradientMap（NearestFilter），暗部不压黑，最低阶 112/255 保留色相 |
| 云的软阶梯 | 单独一套 3 阶 / 2 阶梯度，暗部更亮，避免云被看成雪山 |
| 描边 | 反向外壳：同几何体克隆成 `BackSide` shader 材质，顶点沿法线外扩，深色 `#241f3a` |
| 手绘感 | 所有小道具合并成一个几何体 + 顶点色（同一材质），房屋顶点有轻微扰动 |
| 色彩 | `NoToneMapping` + `SRGBColorSpace`，光强压到 1.1 左右，避免明暗阶梯被高光晒平 |
| 阴影 | 单方向光 2048 硬阴影（PCF，radius 0），阴影相机收紧到岛范围 |

## 四、房屋生长动画

每栋 2.1s（±12% 随机），按“距广场中心的距离”做 0.06–0.12s 交错延迟，形成从中心向外扩散的涟漪。

1. **地基** 0–10%：地面发光圆环扩散
2. **墙体** 10–52%：在 `onBeforeCompile` 里注入世界高度裁剪（`vWy > uProgress` 就 discard，阈值带正弦噪声做锯齿切口）——**不用 scale.y**，所以窗户和描边不会被压扁；描边材质共用同一个 `uProgress` uniform，切口完全对齐
3. **屋顶** 50–80%：以檐口为轴 `easeOutBack` 展开，带轻微过冲
4. **细节** 68–100%：门窗、雨棚、招牌、烟囱依次弹出，窗灯逐渐亮起

点击单栋房屋可单独重播它的生长。


## 六、调参指引

- 想改**时间色彩**：`js/config.js` → `TIME_KEYS`，每个关键帧控制天空三色、雾、光色光强、云色、窗灯亮度
- 想改**房屋数量/街区尺度**：`config.js` → `town.*`（`innerR` / `outerR` 区间，`placeAlong` 的 slot 数）
- 想改**生长节奏**：`config.js` → `growth.perHouse`（单栋时长）/ `spread`（涟漪总延迟）
- 想改**配色**：`config.js` → `PAL`（墙面、屋顶、树、石等数组，随机取用）
- 想关**描边**省性能：面板里的「描边 on/off」按钮，或 `js/main.js` 里 `toggleOutline(false)`

## 七、性能

1080p 下约 **540 draw call / 25 万三角面**，独立显卡或较新集显可稳定 60fps。
像素比封顶 1.5；如仍吃力，可在面板关掉描边（描边会多出一倍网格），或把 `config.js` 的 `outerR` 区间缩短以减少房屋数量、把 `js/systems/pedestrians.js` 里的 `want = 26` 调小以减少行人。
